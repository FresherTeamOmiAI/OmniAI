# Test case nghiệm thu US-14: Admin xem hội thoại

> Cập nhật: 2026-11-18 · Task T-14.1, T-14.2 · Người viết: TuTM
> Code liên quan: `backend/.../conversation/ConversationController.java`, `ConversationFilter.java`, `ConversationService.java`; `web/src/features/conversation-inbox/*`
> Hợp đồng: [api-contracts.md](../specs/api-contracts.md) mục "Hội thoại", màn ở [web.md](../specs/web.md)
> **AC:** Given có hội thoại ở 2 kênh · When lọc theo kênh · Then thấy rawText và finalText; tin bị chặn được tô màu.

US-14 đạt khi test tự động PASS và các TC trình duyệt ở mục C có dòng kết quả đúng như mong đợi.

## A. Test tự động
`cd backend` rồi `mvn test`, lớp `conversation/ConversationApiTest`:
- `filtersByChannelCaseInsensitive`, `pagesNewestFirst` (T-11.2).
- `filtersByDateRangeInVietnamTime`: `from`/`to` gồm cả 2 mốc, tính theo giờ VN (00:30 ngày 01/02 giờ VN thuộc ngày 01/02).
- `filtersConversationsWherePolicyIntervened`: `hasViolation=true` lấy hội thoại có câu bị sửa hoặc bị chặn, bỏ hội thoại sạch; vi phạm ngoài khoảng ngày không tính.
- `filtersHandoffAndCombinesWithChannel`: `handoff=true` kết hợp `channel`.
- `listShowsFlaggedAndHandoffCountsAndLastText`, `rejectsBadDateRange` (`from > to`, sai định dạng → 400).

Web: `cd web` rồi `npm run lint` và `npm run build` (chưa có test tự động phía web).

## B. Chuẩn bị dữ liệu (curl, Git Bash)
Chạy `tools\systembat\run-all.bat` (Docker + backend + ai-brain + web). Tạo hội thoại ở 3 kênh qua simulator:

```bash
curl -s -X POST localhost:8080/api/simulator/web/messages    -H "Content-Type: application/json" -d '{"userId":"us14-web","text":"Kem chống nắng cho da dầu?"}'
curl -s -X POST localhost:8080/api/simulator/shopee/messages -H "Content-Type: application/json" -d '{"userId":"us14-shopee","text":"Mua trên website có rẻ hơn không? Cho mình link"}'
curl -s -X POST localhost:8080/api/simulator/tiktok/messages -H "Content-Type: application/json" -d '{"userId":"us14-tiktok","text":"Serum nào đặc trị mụn?"}'
```
Muốn chắc có 1 câu **bị chặn** mà không phụ thuộc câu LLM: vào `/admin/policy`, gửi câu "Bạn đặt trên website https://omni-demo.local cho rẻ nhé" cho kênh SHOPEE (trang này cũng đi qua simulator nên được lưu). Muốn có câu **cần nhân viên**: tắt ai-brain rồi gửi 1 tin với `userId` mới (như TC-11-07).

# Test case nghiệm thu US-13: Tài khoản web + OTP

> Cập nhật: 2026-11-18 · mục D đặt thử cần đăng nhập (decisions #40); 2026-11-17 · T-13.1 (API OTP + JWT), T-13.2 (màn đăng ký/đăng nhập) · Người viết: LucVT
> Code liên quan: `backend/.../identity/*`, `backend/.../channel/web/WebChatAuthInterceptor.java`, `backend/.../order/*`, `web/src/features/account/*`
> Hợp đồng API: [api-contracts.md](../specs/api-contracts.md), mục "Đăng nhập người mua"
> **AC:** Given nhập email · When nhập OTP 6 số trong 5 phút · Then đăng nhập thành công; sai 5 lần khóa 15 phút; gửi lại OTP cách nhau >= 60s, tối đa 5 lần/giờ

US-13 đạt khi:
- T-13.1: mục A pass, mục C chạy tay được.
- T-13.2: mục B.

## A. Test tự động T-13.1 (JUnit + Testcontainers)
Chạy trong `backend/`: `mvn test -Dtest='OtpAuthApiTest,WebChatAuthInterceptorTest,WebChatAdapterTest'` (cần Docker Desktop). Thời gian giả bằng đồng hồ chỉnh được nên không phải chờ 5 hay 15 phút thật.

| TC | Test (hàm) | Mong đợi |
|---|---|---|
| TC-13-01 | `newCustomerLogsInLinksWebIdentityAndCallsMe` | `202`; verify đúng mã → `200`, `newCustomer=true`; DB có `customer` + `channel_identity` WEB (`external_id`= customer id, `linked_by=OTP`, `consent_at`); `otp_challenge` chỉ có hash; token gọi `/api/me` được |
| TC-13-02 | `returningCustomerKeepsSameAccountAndIdentity` | Đăng nhập lại (email khác hoa/thường) → cùng `customer.id`, `newCustomer=false`, không thêm dòng |
| TC-13-03 | `rejectsMissingConsentAndBadInput` | Thiếu/không tick consent, email sai, mã không phải 6 số, JSON hỏng → `400` đúng `errors[].field` |
| TC-13-04 | `codeExpiresAfterFiveMinutes` | Sau 5 phút → `401 otp_expired` |
| TC-13-05 | `verifyWithoutRequestIsExpired` | Chưa xin mã → `401 otp_expired` |
| TC-13-06 | `fiveWrongCodesLockForFifteenMinutes` | Sai lần 1–4: `401 otp_invalid`, `attemptsLeft` 4→1; lần 5: `423 otp_locked`, `Retry-After: 900`; đang khoá thì mã đúng và xin mã mới đều `423`; sau 15 phút đăng nhập được |
| TC-13-07 | `resendNeedsSixtySecondsAndAtMostFivePerHour` | Gửi lại sau 30 s → `429`, `retryAfterSeconds=30`; mã thứ 6 trong 1 giờ → `429` tới khi mã cũ nhất ra khỏi cửa sổ 1 giờ |
| TC-13-08 | `newCodeReplacesOldOneAndCodeIsSingleUse` | Mã cũ hết hiệu lực khi có mã mới; mã đúng dùng lần 2 → `401 otp_expired` |
| TC-13-09 | `meRequiresValidToken` | `/api/me` không token, token rác, token hết hạn → `401` |
| TC-13-10 | `customerTokenCannotOpenAdminAndAdminBasicStillWorks` | JWT gọi `/api/admin/products`, `/api/conversations` → `401`; Basic admin vẫn `200`; Basic gọi `/api/me` → `401` |
| TC-13-11 | `WebChatAuthInterceptorTest` (2 hàm) | Token đúng → session có `customerId`; thiếu/rỗng/rác/hết hạn/`sub` không phải số → khách vãng lai, handshake vẫn nhận |
| TC-13-12 | `WebChatAdapterTest.toCanonicalUsesCustomerIdWhenLoggedIn`, `handleTextMessageReadsCustomerIdFromHandshakeAttributes` | Có `customerId` → `channelUserId` = id, hội thoại `web:c<id>` |

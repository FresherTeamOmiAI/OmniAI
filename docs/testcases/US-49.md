# Test case nghiệm thu US-49: Đẩy sản phẩm từ hub ra sàn (màn admin T-49.3)

> Cập nhật: 2026-11-18 · Task T-49.3 · Người viết: LucVT
> Code liên quan: `web/src/features/product-admin/SyncStatusCell.tsx`, `ProductAdminPage.tsx`, `api.ts`; backend `sync/AdminSyncController.java` (T-49.1, TuTM)
> Hợp đồng: [api-contracts.md](../specs/api-contracts.md) mục "Đồng bộ sản phẩm ra sàn"; giá/tồn ra sàn: [US-50.md](US-50.md)
> **Tiêu chí T-49.3:** thấy Đã đồng bộ / Đang chờ / Lỗi theo từng kênh

## Chuẩn bị
Backend + web local (worker đồng bộ bật mặc định, simulator Shopee nằm trong backend). Đăng nhập `/admin/products` bằng tài khoản admin.
Shopee chỉ gửi giá, tồn sau khi liên kết: `POST /api/admin/sync/products/{id}/SHOPEE/link` body `{"externalId":"900001"}` (Basic admin).
TikTok cần shop đã ủy quyền (`overview.md`, mục Chạy); chưa ủy quyền thì nhãn TikTok là "Chưa đồng bộ".

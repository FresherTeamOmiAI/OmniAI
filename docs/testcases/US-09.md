### D3. API thủ công (13/11, DB local)
`POST /api/orders {"items":[{"productId":<id CERA-CLE-01>,"quantity":2}]}` → `201`, `status=DEMO`, `channel=WEB`, `unitPrice=369000`, `lineTotal=total=738000`, có `notice`; tồn kho trước/sau = 120/120. Sản phẩm hết hàng → `400` "Không đặt được đơn", `items[0].quantity` "hết hàng".

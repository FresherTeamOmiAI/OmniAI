## A. Test tự động
- Simulator: `cd simulators/tiktok-shop` rồi `mvn test` (35 test: OAuth, gateway, CS, rate limit, webhook).
- Hub: `cd backend` rồi `mvn test` (gồm `channel/tiktok/*`, cần Docker cho `TiktokWebhookIT`).
- Bench: `cd bench` rồi `.venv\Scripts\python -m pytest -q`.
- Hoặc `tools\systembat\test-all.bat` chạy cả 5 phần.

## B. Postman
Collection: `backend/http/OmniAI-tiktok.postman_collection.json`.

### Chuẩn bị
1. Docker Desktop đang chạy. `.env` có `LLM_API_KEY` và 2 dòng `CHATBOT_DB_*` (chép từ `.env.example` nếu thiếu).
2. `tools\systembat\run-all.bat` (mở brain :8000, backend :8080, simulator :8090, web).
3. **Không cần seed gì cho simulator.** Simulator tự có 1 app (`TIKTOK_APP_KEY/SECRET`) và 1 shop test. Buyer và hội thoại sinh ra khi gửi tin. Câu trả lời lấy sản phẩm từ catalog của hub (brain đọc view `chatbot_catalog`), không lấy từ simulator.
4. Import collection vào Postman. Biến nằm ở mức collection (`hub_url`, `sim_url`, `app_key`, `app_secret`, `admin_user`, `admin_pass`), không cần environment.

### Chạy
- **Collection Runner** (khuyên dùng): chạy cả bộ theo thứ tự, vì request sau dùng biến do request trước lưu (`state`, `conversation_id`, `access_token`, `shop_cipher`). Mất khoảng 35 s–2 phút tùy độ trễ Gemini.
- **Từng request**: chạy mục 0 và 1 trước. Mục 3, 4 cần `conversation_id` (chạy 1 request ở mục 2 trước).
- **newman**: `npx -y newman@6.2.1 run backend/http/OmniAI-tiktok.postman_collection.json`.
- Ký request và webhook do pre-request script làm (thuật toán ở [tiktok.md](../channel-api/tiktok.md) mục 3, 5), nên gọi được Open API của simulator y như app thật.

### Danh sách TC (khớp tên request)
| Mục | TC | Kỳ vọng |
|---|---|---|
| 0 | Reset simulator | Xóa hội thoại, token, webhook; hub phải ủy quyền lại |
| 1 | Lấy URL ủy quyền → Seller bấm Đồng ý → Xem credential | Hub lưu credential `ACTIVE`, không trả token ra ngoài |
| 1 | Callback với state giả | `400 invalid_state` (chống CSRF) |
| 2 | Buyer hỏi sản phẩm | Có tin ROBOT trả lời, nhắc "chống nắng" |
| 2 | Buyer xin link | Câu khách nhận không có link/website (luật TIKTOK) |
| 2 | Log giao webhook | Mọi webhook giao được, hub trả 200 < 3 s |
| 3 | Get Access Token, Get Authorized Shops, Get Conversations, Get Messages, Send Message, Mark Read, Get Shop Webhooks, Refresh | `code = 0`; hub đã đăng ký NEW_MESSAGE, SELLER_DEAUTHORIZATION |
| 4 | Send Message thiếu content; page_size = 21 | `45101002` (invalid_params) |
| 4 | Token sai; sai chữ ký | `105001`; `106001` |
| 4 | Cho token hết hạn → gọi lại; buyer hỏi | `105002`; hub tự refresh, buyer vẫn nhận trả lời |
| 4 | Webhook trùng | Có bản gửi trùng, buyer nhận 1 câu trả lời |
| 4 | Thu hồi scope | Không có trả lời; log backend báo lỗi scope, không retry |
| 4 | Từ khóa nhạy cảm | Sàn trả `45101006`, hub gửi `fallback_message` |
| 5 | Webhook ký đúng; gửi lại y hệt; sai chữ ký; timestamp cũ | 200 (< 3 s); 200 không xử lý lại; `401 invalid_signature`; `401 stale_timestamp` |

Không test được bằng Postman: rate limit 50 request đồng thời (Runner chạy tuần tự). Ca này có ở `RateLimitTest`.

### Lỗi thường gặp
- Mục 2 không có `reply`: backend hoặc brain chưa chạy, hoặc chưa chạy mục 1 sau khi reset/restart simulator (simulator giữ token trong bộ nhớ).
- Brain không khởi động, báo thiếu `CHATBOT_DB_URL`: `.env` cũ, chép thêm 2 dòng `CHATBOT_DB_*` từ `.env.example` rồi **khởi động lại backend** (backend bật đăng nhập cho role `chatbot_reader` lúc khởi động).
- `106001` ở mọi request mục 3: `app_key/app_secret` của collection khác `.env`.

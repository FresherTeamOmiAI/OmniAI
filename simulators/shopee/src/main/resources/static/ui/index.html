    Nối với hub

    • Khóa SHOPEE_PARTNER_ID/KEY, SHOPEE_SHOP_ID, SHOPEE_ACCESS_TOKEN phải trùng giữa simulator và backend (cả hai đọc .env).
    • Hub gọi simulator qua SHOPEE_SIM_URL (mặc định http://localhost:8091).
    • Giá/tồn: liên kết item_id ở POST /api/admin/sync/products/{id}/SHOPEE/link (Basic admin), sau đó sửa sản phẩm trên hub.
    • Chat: buyer gửi tin ở tab Chat → push code 10 → hub trả lời qua v2.sellerchat.send_message.
